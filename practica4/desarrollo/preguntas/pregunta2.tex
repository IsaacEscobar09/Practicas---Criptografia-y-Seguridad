\subsection{Pregunta 2}

¿Cuál es el nombre de la persona denominada \texttt{contacto administrativo} del dominio anterior? 

\begin{respuesta}

Usando el mismo comando que en la pregunta anterior, \texttt{whois uam.mx}, podemos encontrar en la parte de contacto administrativo (\texttt{Administrative Contact}) del dominio, se muestra el nombre de \textbf{Victor Alcaraz Paramo} asignado para este rol, también se muestran los nombres de Gabriel Aguilar Martinez y Maricela Garcia, tomando como roles de contacto técnico y contacto de facturación respectivamente.

\end{respuesta}
